# AI Agent 开发工程师

> 雷特科技 · 40-60K · 13薪

## 岗位职责

- AI 智能体架构设计与开发：负责设计、构建和优化多模态 AI Agent 系统，包括单智能体和多智能体协作架构，快速响应复杂业务场景需求。
- 智能体核心能力构建：设计和实现基于 LLM 的 Agent 核心组件，包括推理规划（ReAct/CoT）、记忆管理、工具调用（Function Calling）、多轮对话、意图理解和知识检索增强（RAG）。
- Agent 工作流开发：构建复杂的 Agent 工作流系统，支持任务分解、并行执行、错误处理和结果聚合，实现端到端的自动化解决方案。
- 多智能体系统设计：主导多 Agent 协作框架的设计与实现，包括 Agent 间通信、任务分配、协作策略和冲突解决机制。
- 垂直领域 Agent 应用：参与智能客服 Agent、风控审核 Agent 等垂直场景的产品化开发，支持文本、图像、视频等多模态内容的智能处理。
- Agent 性能优化：持续优化 Agent 的响应速度、推理准确性和资源消耗，建立完善的评测体系和监控机制。

## 任职要求

### 基础技能

- 计算机相关专业，本科及以上学历，3 年以上 AI/NLP 相关开发经验。
- 精通 Python 开发，熟悉 Go/PHP 等语言，具备优秀的系统架构设计和高并发处理能力。

### Agent 开发核心技能

- 深度掌握 Agent 开发框架：熟练使用 LangChain、LlamaIndex、CrewAI、AutoGen、Haystack 等主流 Agent 开发框架，有丰富的生产环境部署经验。
- 精通 Prompt Engineering：深度理解 Chain-of-Thought、ReAct、Tree-of-Thoughts 等推理范式，具备复杂 Prompt 设计和优化能力。
- 工具集成与函数调用：熟练实现 Agent 与外部工具/API 的集成，掌握 Function Calling、Plugin 机制和工具链构建。
- 向量数据库与检索：熟悉 Pinecone、Weaviate、Qdrant 等向量数据库，具备 RAG 系统设计和优化经验。

### 进阶能力

- 模型微调与优化：具备 LLM 微调经验（LoRA/QLoRA），了解 Agent 专用模型训练和优化方法。
- LLMOps 实践经验：熟悉模型部署、版本管理、A/B 测试和性能监控，有完整的 Agent 产品上线经验。

## 加分项

- 熟悉多模态模型（GPT-5、Claude-3 等）在 Agent 中的应用。
- 有开源 Agent 项目贡献或技术分享经验。
- 了解强化学习在 Agent 训练中的应用。
