# 轻游 Agent 高级工程师（Agentic Engineer）

> 腾讯 IEG · 深圳 · 3 年以上经验

## 岗位职责

1. 负责轻游戏创作 Agent 的核心设计与开发，参与从需求分析到方案落地的全流程；
2. 针对游戏开发流程，设计高效的上下文工程，提升 Agent 对开发场景的理解与响应能力；
3. 规划并优化 Agent 的工作流，确保其能够高效适配游戏开发的各个环节，持续提升生成内容的质量；
4. 深入分析二方工作室现有工作流，识别适合 Agentic 改造的环节，推动实施并验证效果；
5. 基于改造后的工作流，总结并推广最佳实践，为团队提供可复用的方法论与工具支持。

## 岗位要求

1. 拥有 3 年以上游戏行业技术岗位从业经验，熟悉游戏开发全流程及关键技术点；
2. 具备主程经验者优先，同时欢迎前后端全栈工程师或具备策划/美术背景的复合型人才；
3. 熟练掌握 AI Coding 工具，对技能（Skill）、模型上下文协议（MCP）、检索增强生成（RAG）等技术原理有全面理解；
4. 具备优秀的逻辑思维与问题解决能力，能够独立承担模块设计与优化任务；
5. 良好的跨团队沟通与协作能力，能够推动技术方案在业务场景中的落地。

## 加分项

1. 有大型游戏项目主程或技术负责人经验，主导过复杂系统设计与优化；
2. 有复杂 Agent 研发经验者优先（单用户请求对应 LLM 请求超过 20 次）；
3. 参与过 AI 辅助开发工具或平台的研发，有将 AI 技术深度融入工作流的实际案例；
4. 对游戏开发有浓厚兴趣，有独立作品。

## 岗位亮点

1. 参与前沿的轻游戏创作 Agent 研发，直接推动 AI 技术在游戏开发领域的创新应用；
2. 提供开放的探索空间，鼓励尝试新技术与新方案，助力个人技术与创新能力的高速成长；
3. 工作环境开放包容，团队氛围积极向上，提供与行业专家交流学习的机会；
4. 丰厚的薪酬福利与清晰的职业发展路径，为优秀人才提供广阔的成长平台。
