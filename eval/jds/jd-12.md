# 软通动力-AI Agent开发工程师

软通动力：职位描述

工作职责

核心架构设计与开发：负责基于大语言模型（LLM）的智能体（Agent）核心架构设计，主导任务规划（Planning）、记忆机制（Memory）、工具调用（Tool-use）及多智能体协作等核心模块的开发与优化，确保Agent具备自主决策与高效执行能力。

Agent框架落地与优化：深度应用 LangGraph 和 AgentScope 等前沿框架，完成AI智能体应用的POC验证、功能开发与生产上线；探索并引入业界前沿技术，保障Agent系统在复杂业务场景下的高效、稳定运行。

多智能体协作（Multi-Agent）探索：基于 AgentScope 等框架设计并实现多智能体协作模式，解决跨部门、跨系统的复杂业务流程自动化问题；设计Agent间的通信协议、任务分配与冲突解决机制。

工作流编排与工具链集成：利用 LangGraph 进行复杂工作流的编排与状态管理；负责外部工具（API、数据库、第三方服务）的集成与封装，设计灵活的工具体例策略，打通Agent与业务系统的无缝交互。

具体要求

任职要求学历与经验：计算机、软件工程、人工智能等相关专业本科及以上学历，3年及以上AI应用开发或大模型应用开发经验。

编程与工程能力：具备扎实的编程功底，精通 Python（兼顾Go/Java者优先），熟悉常用数据结构、算法与设计模式；熟悉分布式系统、微服务架构，能独立完成高可用场景下的应用开发。

Agent框架专精：深入理解 AI Agent 的核心原理，必须具备 LangGraph 或 AgentScope 框架的实战开发经验；熟练掌握ReAct、Plan-and-Execute、Reflection 等高阶推理策略。

工具与存储生态：精通 Function Calling / Tool Use 技术；熟悉向量数据库（Milvus、Chroma、Weaviate等）及图数据库在Agent记忆管理中的应用；熟悉 Docker/K8s 容器化部署及 CI/CD 流程。

加分项

有完整 AI Agent 产品从0到1落地经验，或在智能客服、自动化办公、企业级Agent等场景有实战经验。参与过LangGraph、AgentScope 等开源 AI Agent 项目的代码贡献，或有个人技术博客、GitHub项目分享。具备大模型微调（LoRA/QLoRA）经验。
