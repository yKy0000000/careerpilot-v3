# eval/jds —— 真实 JD 存放

> 供 L3「5 份 JD × top-3 人工命中观察」使用，后续也进 L8 标注集。

## 格式要求

- 每个 JD 一个 `.md` 文件，**纯原文即可，不需要 `#`/`##` 结构**（JD 是 query，不进切块）
- 首行写一个 `# 公司-职位` 当文件名标识（可选，便于识别，不会进 embedding）
- 从招聘网站**原样复制** JD 正文（岗位职责 / 任职要求 / 加分项）

## 硬性规则：必须真实

- 只放**真实投过的、或真实招聘网站上的** JD，禁止 AI 生成或编造
- 理由：L3 观察的是真实检索效果，L8 的 ground truth 依赖"真的投过"的 JD
- 来源建议：Boss 直聘 / 拉勾 / 牛客 / 公司官网 careers 页

## 命名

`jd-01.md`、`jd-02.md` … 即可，或 `jd-<公司>-<岗位>.md`
