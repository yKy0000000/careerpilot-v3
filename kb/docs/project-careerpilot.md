# 个人项目：CareerPilot AI 求职助手

> 技术栈：Python / FastAPI / LangChain / RAG / SQLModel / SQLite

## 异步后端

基于 FastAPI 构建异步 API 服务，使用 SQLModel + SQLite 管理公司、岗位、投递记录和 AI 分析结果，封装 Dashboard 统计、高优先级岗位、待跟进投递、公司画像等业务接口。

## LLM 应用

基于 LangChain 编排 JD 解析、岗位匹配、面试题生成、行动建议生成等任务链，将岗位 JD、简历文本、项目经历和投递状态组合为 Prompt 上下文，输出结构化分析结果。

## RAG 增强

构建个人求职知识库，对简历、项目经历、技术笔记、面试复盘和历史 JD 进行向量化索引，在岗位分析时召回相关材料，提升技能匹配、项目映射和面试问题生成的针对性。

## 数据闭环

设计用户反馈与分析记录沉淀机制，保存 AI 输出、用户评分、人工修正和采纳结果，支持后续构造指令微调数据集。

## 前端工作台

实现轻量级 Web UI，支持 Dashboard 总览、岗位/JD 导入、CRUD 管理、AI 分析结果查看、待跟进任务聚合和高优先级岗位筛选，形成可本地运行的端到端产品原型。
