## 零、这次讨论真正产出了什么

一句话：**引入"平凡基线"作为所有指标的强制对照，据此判定了三项能力的生死。**

原来的 L9 报表（ρ=0.4、gaps=0.94、evidence=0.94）里，
- 一个数字是**口径造出来的**（gaps 池化）
- 一个数字**连常数预测器都打不过**（match_score）
- 只有一个数字**经得起阴性对照**（evidence）

补完基线后，结论从"漂亮但站不住"变成"难看但每个数都能追问"。

## 二、双方分歧的最终裁定

### 2.1 Claude 撤回：ρ 不稳的归因

原稿写「**不是**模型不确定，**是**统计量选型错误」——**这个"不是…是…"的句式错了**。

DeepSeek 正确指出两个原因**同时成立**：
1. 模型确实非确定（同代码同参数连跑两遍，30 条里 **11 条 match_score 翻转**）—— 这是**源**
2. Spearman 在重 tie 下方差极大 —— 这是**放大器**

把源归零只治放大器，会误导后续（以为换个统计量就解决了复现性）。**Claude 此点撤回，采纳 DeepSeek 表述。**

> 附：`seed` 问题已澄清 —— 确实加过 `seed=42`，实测无效后删除。属诚实实验记录，`AGENTS.md` 表述成立。
> **唯一遗留动作**：在 `report.md` 或 `vault/` 留一行"试过 seed=42 仍非确定，故移除"，否则代码里看不到 seed，面试时缺可追溯依据。

### 2.2 Claude 撤回：±1 档 77~83% 不能当正面指标

DeepSeek 用平凡基线打穿了它（0.83 < 0.97）。**完全成立，采纳，不再报 ±1 档。**

### 2.3 DeepSeek 需修正：gaps "中等" 的措辞

DeepSeek 第四节写「gaps（逐 JD）recall ~0.66~0.72（**中等**），不是 0.94」。

**"中等"是没有基线的形容词。** DeepSeek 对 match_score 用了平凡基线这把刀，
**但没有对 gaps 用同一把刀**。补上后：

> gaps recall 0.72 = 等预算平凡基线 0.357 的 **2.0 倍**，precision 同样 2 倍。

这不是"中等"，这是**项目里唯一一条"LLM 确实产生了 JD 特异性判断"的硬证据**。
它是整个项目仅存的正面主张，措辞上不能自我贬低。

### 2.4 双方共识（无争议，直接执行）

- gaps 池化口径是 bug，改逐 JD ✅
- agent vs workflow 无统计差异，原"agent 反而更差"的结论是池化伪影 ✅

### F. match_score 常数基线 + 标签熵

```python
import collections, math, sys; sys.path.insert(0, '.')
from eval.run import load_dataset

h = [r['human_match_score'] for r in load_dataset()]
for const in [40, 60, 80]:
    print('常数基线=%d: MAE=%.1f 完全一致=%.2f ±1档=%.2f' % (
        const,
        sum(abs(const - x) for x in h) / len(h),
        sum(const == x for x in h) / len(h),
        sum(abs(const - x) <= 20 for x in h) / len(h)))
cnt = collections.Counter(h); n = len(h)
H = -sum(c / n * math.log2(c / n) for c in cnt.values())
print('标签熵=%.2f bit (4档均匀应为2.00) -> 有效档位数=%.1f' % (H, 2 ** H))
```

### G. gaps 等预算平凡基线（本轮决定性数据）

```python
import json, collections, sys; sys.path.insert(0, '.')
from eval.run import load_dataset, load_aliases, canonical_gaps

rows = {r['jd_id']: r for r in load_dataset()}
am = load_aliases()
allh = {jid: canonical_gaps(r['human_gaps'], am) for jid, r in rows.items()}
freq = collections.Counter()
for s in allh.values(): freq.update(s)

for arm in ['workflow', 'agent-baseline']:
    v = [r for r in (json.loads(l) for l in open(f'eval/raw_{arm}.jsonl', encoding='utf-8') if l.strip())
         if r['model_result']]
    sizes = [len(canonical_gaps(r['model_result']['gaps'], am)) for r in v]
    k = round(sum(sizes) / len(sizes))
    tp = fp = fn = 0
    for r in v:
        hg = allh[r['jd_id']]; m = canonical_gaps(r['model_result']['gaps'], am)
        tp += len(hg & m); fp += len(m - hg); fn += len(hg - m)
    top = set(x for x, _ in freq.most_common(k))
    btp = bfp = bfn = 0
    for jid, hg in allh.items():
        btp += len(hg & top); bfp += len(top - hg); bfn += len(hg - top)
    print(f'{arm}: 模型平均输出 {sum(sizes)/len(sizes):.1f} 个gap/JD')
    print(f'   模型        P={tp/(tp+fp):.3f} R={tp/(tp+fn):.3f}')
    print(f'   等预算平凡  P={btp/(btp+bfp):.3f} R={btp/(btp+bfn):.3f}  (k={k})')
    print(f'   -> recall 提升 {(tp/(tp+fn))/(btp/(btp+bfn)):.1f}x')
```
