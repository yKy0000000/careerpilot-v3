## 二、反驳点 1：ρ 不稳的归因——不是「或」，是「且」

复核原文：「ρ 不可复现的归因错了：不是模型不确定，是统计量选错」。

**两个原因同时成立，不能把模型非确定归零：**

1. **模型非确定是硬事实**。同样代码、`temperature=0`、`seed=42`，连跑两遍 workflow，30 条里 **11 条 match_score 翻转**（jd-04: 60→20、jd-06: 80→60、jd-11: 60→80……）。同样的输入和参数，输出就变了——这跟统计量无关。
2. **Spearman 重 tie 放大了这种翻转**。人工分 60×17 / 80×9 / 40×3 / 100×1，tie 率过半，ρ 对少数翻转极敏感。

正确的因果链是：**模型非确定（源）+ Spearman 不适用（放大器）**，两个都得处理。把源归零、只留放大器，会误导后续——比如以为换个统计量就解决复现性问题。

（注：换 Kendall tau-b / 加权 Kappa 的建议本身是对的，只是它治的是放大器，不是源。）

## 三、反驳点 2：±1档 77~83% 不能写简历——它比平凡基线还差

复核对 evidence 做了阴性对照（null baseline 0.008 vs 模型 0.94），**却没有对 match_score 做同款平凡基线**。补上：

| 指标 | workflow | agent | 平凡基线（永远打众数 60） |
|---|---|---|---|
| MAE | 19.3 | 20.0 | **9.3** |
| 完全一致 | 0.30 | 0.20 | **0.57** |
| ±1档 | 0.77 | 0.83 | **0.97** |

模型的 match_score 在**三个指标上全部输给「永远输出众数 60」这个常量预测器**：
- MAE 差一倍（20 vs 9.3）
- ±1档 0.83 低于平凡的 0.97
- 完全一致 0.20~0.30 低于平凡的 0.57

原因：模型带系统性低估（挤在 40/60，人工挤在 60/80），且排序近乎随机（ρ≈0.2）。

所以「±1档内命中 77~83% 是能写进简历的结论」不成立——它连常量预测器都打不过。这不是正面数字，是「整体打分比瞎猜还差」的证据。

## 四、修正后的结论

| 指标 | 真实结论 |
|---|---|
| evidence 溯源率 | 0.94，经阴性对照（null 0.008）验证可信 —— 唯一强正面 |
| gaps（逐JD） | recall ~0.66~0.72，中等，不是 0.94 |
| match_score | 比平凡基线差（MAE 20 vs 9.3）—— 整体打分无用且有害 |
| agent vs workflow | 无统计差异（Wilcoxon p=0.61） |

正确的叙事不是「±1档 77%」，而是：

> match_score 的 MAE 20 比平凡基线 9.3 还差，说明 LLM 的整体打分不仅没用、是有害的；真正的价值在逐项 gap 分析 + 证据溯源。

负结果 + 平凡基线对比，才是这个项目最经得起追问的部分。
